# 职练 · 可点原型 v0.1

> 单文件 HTML，无依赖、无构建。双击 `index.html` 即可打开（Windows 也可双击 `打开原型.bat`）。
> 用途：和你确认**信息架构、交互流程、页面信息量**，不是最终视觉与真实功能。

---

## 已实现（7 个视图，都可点）

| 视图 | 可交互点 |
|---|---|
| **工作台** | 今日三件事（可勾选）、四个状态卡、本周状态与建议 |
| **简历** | 版本条切换、贴 JD → **分析匹配**（模拟 0.9s）、关键词覆盖/缺口、逐条改写 → **一键采用**（匹配分实时上升）、导出提示 |
| **面试陪练** | 岗位/人格/模式/轮次选择、开始面试、数字人 5 状态（待机/倾听/思考/说话/反馈）、逐题提问与追问、文字作答、录音按钮（模拟） |
| **复盘报告** | 总评 + 四维分、逐题展开、低分原因、参考答案、回放进度条（模拟） |
| **错题本** | 三个弱项、7 天训练计划（可勾选）、最近错题表 |
| **投递台账** | 统计卡、投递阶段表、关联练习记录跳转 |
| **设置** | 账号、数据导出/删除、隐私开关、录音保存开关、模型 Key |

**数字人**：Canvas 2D 简笔画占位（真机版本按调研结论做 3 帧嘴型 + 5 状态基图）。

---

## 诚实标注：哪些是模拟的

- 数字人是 **Canvas 简笔画占位**，不是最终美术资产；
- 语音是 **按钮模拟**，没有接 STT/TTS；
- 评分、练习记录、投递数据是 **写死的示例**；
- 导出、保存、删除、连通性测试只弹提示，不真的执行；
- 简历 A4 预览是 CSS 排版，不是真实 PDF 渲染。

## 设计说明

- 视觉：纸面（#f7f3ea）+ 墨色 + 朱红（#b23a2c）单强调色，标题用宋体，延续上一版「编辑部杂志」的克制感，但重新做过；
- 移动端：≤820px 顶部导航变底部 7 项 tab，三栏简历变单栏（预览优先）；
- 打印：`@media print` 已隐藏导航与侧栏，为后续 PDF 导出留位置。
