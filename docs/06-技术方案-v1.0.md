# 技术方案 v1.6 · OfferFit MVP

> 日期：2026-11-10 ｜ 状态：**已实现并跑通（v0.7）**（本地运行，`app/`）
> 决策：**D5 = FastAPI + 原生前端 + SQLite**（沿用上版规则引擎）

---

## 1. 架构

```
浏览器（原生 HTML/CSS/JS，零构建）
        │  fetch /api/*
FastAPI（app/main.py：路由 / 请求校验 / 静态托管）
        │  函数调用
engine/（从「简核/core」原样移植，不认识 HTTP）
  lexicon  profile  parse  lint  jd  rewrite  interview  drill
        │
SQLite（app/data/zhilian.db，WAL）  ← profile / sessions / applications
```

**原则**：引擎与框架解耦（和上版一致）。将来换存储或加鉴权，只改 `main.py` / `store.py`。

## 2. 目录

```
app/
├── main.py            FastAPI：16 个接口 + 静态托管
├── store.py           SQLite：profile / sessions / applications
├── engine/            规则引擎（从简核 core 移植 8 个模块）
│   ├── lexicon.py     词库（弱动词/空话/量化正则）
│   ├── profile.py     档案结构、完整度、bullet 遍历
│   ├── parse.py       简历文本 → 档案（已接 docx/txt 上传）
│   ├── ats.py         ATS 可解析性：阶段 A 结构预检 + 阶段 B 导出回读
│   ├── render_pdf.py  档案 → 可打印 HTML → A4 PDF（Playwright + 本机 Edge）
│   └── stt.py         本地语音转写（faster-whisper base，热词来自档案）
│   ├── lint.py        HR 四维诊断
│   ├── jd.py          JD 拆词 / 匹配 / 缺口 / 硬门槛
│   ├── rewrite.py     规则改写 + 数字防新增
│   ├── interview.py   追问预测（出题依据）
│   └── drill.py       作答四检查点 + 追问 + 改法
├── static/index.html  单文件前端（7 个视图，零构建）
└── data/
    ├── sample_profile.json   示例档案（示例用户）
    └── zhilian.db            SQLite（运行时生成）
```

## 3. 接口清单（已实现）

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/api/health` | 健康检查 |
| GET | `/api/bootstrap` | 首屏一次性数据：档案 / 完整度 / 诊断 / **ATS** / 投递 / 练习记录 / 最近报告 |
| POST | `/api/lint` | 重跑四维诊断 |
| POST | `/api/jd` | JD 关键词、匹配分、缺口、硬门槛、建议 |
| POST | `/api/rewrite` | 单条 bullet 的 A/B/C 三版规则改写 + 数字防新增 |
| POST | `/api/bullet` | 采用改写：写回档案并返回新诊断 + ATS |
| POST | `/api/ats` | ATS 可解析性检查（阶段 A 结构预检，23 条规则） |
| POST | `/api/parse-upload` | 上传 .docx / .txt → 规则解析成档案（返回预览，不直接覆盖） |
| POST | `/api/profile/import` | 确认导入解析出的档案 |
| POST | `/api/tts` | 中文语音合成（edge-tts，免费），返回 mp3 URL，本地缓存 |
| POST | `/api/ats/render` | **ATS 阶段 B**：渲染 A4 PDF → 回读文字层 → 合并报告，并给出可下载 PDF |
| POST | `/api/stt` | **本地语音转写**：WAV（16k 单声道）→ faster-whisper base → 文本 + 分段时间戳 |
| GET/POST | `/api/llm/config` | LLM 配置（provider/base_url/model/api_key；Key 只回显后 4 位） |
| POST | `/api/llm/test` | 连通性测试（返回延迟与回复） |
| GET | `/api/variants` | 一岗一版列表（每个版本带诊断分） |
| POST | `/api/variants` | 以当前档案 + JD 新建版本 |
| POST | `/api/variants/activate` | 切换版本（切走前自动保存当前版本） |
| DELETE | `/api/variants/{id}` | 删除版本（通用底版不可删） |
| GET | `/api/variants/diff` | 与通用底版对比（条数 + 新增/删除/修改明细） |
| GET | `/api/sessions/{sid}` | 单场练习详情与报告（复盘页历史练习） |
| GET | `/api/export/all` | 全量数据导出（档案/版本/练习/投递，JSON，不含 Key） |
| POST | `/api/data/reset` | 重置全部数据（需确认词 DELETE） |
| PATCH/DELETE | `/api/apps/{id}` | 投递台账改状态 / 删除 |
| GET | `/checklist` | 内置测试清单页面 |
| POST | `/api/practice/start` | 开一场练习：出题（基于简历 + JD + 缺口） |
| POST | `/api/practice/answer` | 提交一答：四检查点评分 + 自动追问或下一题 |
| POST | `/api/practice/finish` | 提前结束 / 生成报告 |
| GET | `/api/practice/latest` | 最近一次报告 |
| GET | `/api/sessions` | 练习记录列表 |
| GET | `/api/apps` | 投递台账 |
| POST | `/api/apps` | 新增投递 |

## 4. 数据模型（MVP）

```jsonc
// profile（单用户单档案）
{ "basic": {...}, "intent": {...}, "education": [...],
  "internships": [{"org","role","time","bullets":[{"text","evidence","status"}]}],
  "projects": [...], "skills": [...], "summary": "", "evidence": [...] }

// sessions（一场练习，JSON 存整场，便于快速迭代）
{ "id","role","jd","mode","persona","rounds","questions":[
    {"q","kind","point","frame","trap","answer","score","dims","fix","grade","followDepth"}],
  "cursor","status","report":{ "total","dims","questions","weakPoints","stats" } }

// applications
{ "id","company","role","stage","note","created_at" }
```

> 会话先存 JSON：等语音/报告结构稳定后再拆表（避免过早抽象）。

## 6. 运行

```powershell
# 方式一：双击 启动OfferFit.bat
# 方式二：
cd app
python -m uvicorn main:app --host 127.0.0.1 --port 8848
# 打开 http://127.0.0.1:8848
```

依赖：`fastapi`、`uvicorn`、`python-docx`、`python-multipart`、`edge-tts`、`playwright`、`pypdf`、`faster-whisper`（模型 base 已缓存在 `~/.cache/huggingface`，约 145MB）。Playwright 用 `channel="msedge"` 复用本机 Edge，不下载 Chromium。模型大小可用环境变量 `ZHILIAN_WHISPER_MODEL` 切换（tiny/base/small）。引擎与 ATS 规则本身零第三方依赖。
