## 已知限制（不算失败）

- 单用户本地版：没有账号 / 点数 / 多端同步；
- 数字人是代码绘制的简笔画，不是美术资产；
- STT 首次加载模型需要几秒，识别中文偶尔有个别字误（可手改）；
- ATS 阶段 B 只针对自建模板与导出 PDF，深度版面规则有限；
- 实时语音打断（barge-in）按设计放 P1。
