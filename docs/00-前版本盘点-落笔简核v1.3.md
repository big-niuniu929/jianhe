## 0. 结论先行

上一版**不是原型，是一个跑通了完整商业闭环的可运行 MVP**：

- 13,611 行代码（py / js / html / css，34 个文件）、49 个 HTTP 接口、16 张 SQLite 表；
- **零第三方依赖**（Python 3.9+ 标准库 + 原生 JS），单文件即可分发；
- 已上线过公网试玩入口，已有账号、点数、兑换码、漏斗后台、毛利计量。

它真正的价值不在 UI，而在三层资产：

| 层 | 资产 | 为什么值钱 |
|---|---|---|
| **引擎层** | 规则诊断 / JD 匹配 / 改写防新增 / 追问预测 / 岗位地图 / 坑库 / 陪练 | 离线可用、成本为 0、可累积，不依赖模型 |
| **商业层** | 匿名可用 + 导出处收费 + 点数 + 兑换码 + 漏斗 + 成本计量 | 已用真实接口验证过一遍，改改就能用 |
| **结论层** | 定位选择、定价修正、手机端、打印契约、计费口径 | 都是踩坑换来的，重做会重踩 |

**新产品的正确起点：继承引擎与商业机制，重做定位与信息架构，而不是从零重写。**

## 2. 功能全图

### 2.1 简历引擎（核心，规则版全部免费）

| 功能 | 实现方式 | 关键点 |
|---|---|---|
| 导入解析 | 规则切分（板块标题 + 时间区间 + bullet） | 支持粘贴 / `.docx` / `.txt`，切完可逐项确认 |
| HR 诊断 | 纯规则四维打分 | 首屏 6 秒 / 经历价值 / 语言专业度 / 排版结构；每条问题指到具体句子 |
| 岗位定向 | JD 关键词 ∩ 档案 + 硬门槛 + 隐性信号 | 匹配度、缺口词；「与算法团队协作」识别为协作对象而非技能 |
| 关键词召回 | 165 词库 + 长词优先去重 | 修掉「MySQL 含 SQL」重复计数导致的匹配分母虚高 |
| 逐条改写 | 规则版 / 大模型版 | 三版侧重 + **数字防新增校验**（原文没有的数字直接标红） |
| 证据核验 | 数字回溯 evidence 字段 | 无证据数字标黄，点一下能改 |
| 追问预测 | 按「可攻击点」出 8–12 题 | 每题带考察点、STAR 框架、常见坑 |
| 导出 | 浏览器打印，保留文字层 | 验证 1 页、ATS 可解析 |

### 2.2 岗位地图 · 实习避坑（v1.2）

解决「编简历编不圆满」：不是词汇量问题，是缺具体到不用回忆的事实。

| 功能 | 内容 |
|---|---|
| 岗位地图 | 11 个岗位族 / 96+ 词条：定位、汇报对象、考核指标、日周月节奏、行业与组织上下游 |
| 专业词汇 | 每词 5 字段：释义 / 为什么这么叫 / 面试怎么用 / 用错会被怎么问 / 难度 |
| 诚实边界 | 三阶段「能这么写 / 别这么写」，掐掉「独立负责」「从 0 到 1」等越界表述 |
| 细节题 | 每族 4 题，「真做过能秒答、编的人必卡」 |
| 乱编检测 | 6 条启发式规则：角色矛盾 / 量级越界 / 无口径百分比 / 超 300% 提升 / 短期搭体系 … |
| 实习坑库 | 42 条（12 通用 + 30 分族）：场景 / 早期信号 / 事前避 / 已踩救 / 简历怎么写 |
| 入职必问 8 句 | 转正名额、指导人是谁等「该问但不敢问」的话 |
| AI 定制 | 接 DeepSeek 后按具体 JD 重新生成；失败自动降级规则库且**不扣点** |

### 2.3 一岗一版 · 手机可用（v1.3）

| 功能 | 做了什么 | 设计理由 |
|---|---|---|
| 版本条 | 顶部 chips：名字 + 诊断分 + 投过几次，一点切换 | 一天切十几次版本，二段式「保存再加载」必被放弃 |
| 新建版本 | 以当前档案为底复制，绑一段 JD，名字自动「公司 · 岗位」 | 复制而非改唯一那份——用户不敢在唯一版本上试错 |
| 自动回写 | 改动只写当前版本，切走再切回不丢 | 丢改动最伤信任 |
| 版本差异 | 与通用底版逐条对比：改了/加了/删了/还差几个关键词 | 让用户确认「这一版真的为这个岗改过」 |
| 按 JD 定制 | 原文 / 改后 / 覆盖哪个缺词 / 为什么改 / 采用前必须确认什么，一键采用 | 真正的付费点：给能直接采用的句子 |
| 别写清单 | JD 要求但简历完全没有的，明确说「别写」 | 宁可少一个关键词，也别让面试崩在第一轮 |
| 手机版 | ≤860px 三栏变分段；A4 缩略图换成阅读模式 | 390px 宽缩放的 A4 正文只有 6px，手机是另一种阅读方式 |
| 打印不动 | `@media print` 强制回 A4 | 手机改、电脑打是真实工作流 |

### 2.4 商业机制（v1.1，创业项目的地基）

| 模块 | 做了什么 | 为什么 |
|---|---|---|
| 账号 | 邮箱 + PBKDF2（20 万次）口令，Cookie 会话 | 不做短信（成本+备案）、不做三方登录（审核周期） |
| 匿名可用 | 未注册能用全部功能，只在**导出**时拦 | 一上来给登录墙，转化率砍七成 |
| 数据迁移 | 注册时把匿名的 `s:xxx` 全批挂到 `u:xxx` | 不给用户「重来一遍」的机会 |
| 额度 | 注册送 3 次，导出扣 1 次 | 全产品唯一收费点，放在价值最高处 |
| 兑换码 | 后台生成、用户自助激活 | MVP 收钱 = 微信收款 → 手工发码（零支付接口/手续费/合规风险） |
| 留资 | 撞墙时留微信/手机 | 「说过要买没买」比付费用户更值钱的前置信号 |
| 漏斗看板 | `/admin?key=xxx` 七步漏斗 + 留存 + 解析失败率 + 自动诊断最大漏点 | 统一按**人数**口径（混用次数会算出 300% 假转化率） |
| 水印 | A4 预览平铺淡纹 | 挡截图不挡阅读 |
| 会员 / 点数 | 会员 ¥4.9 一次性：不限次导出 + 知识库全解锁 + 赠 20 点；点数按 AI 调用扣 | 导出不烧算力所以敢放开；AI 有真实成本所以按点走 |
| 成本计量 | 每次 AI 调用记 prompt/completion token、真实成本、实收、毛利 | 按量计费却不知道自己花多少钱 = 赌 |


## 5. 已验证的硬结论（重做时不要推翻，除非有反证）

1. **卖「敢投敢面」，不卖「写得漂亮」**。AI 生成简历已被市场反向惩罚（HR 识别能力上升，完美但空的简历降低面试率）。
2. **规则引擎默认，AI 只是增量**。断网、没预算、演示翻车时功能不能消失；模型失败自动降级且**不扣点**。
3. **免费能力不因未登录整块消失**。收费点放在产品价值最高处（导出），不是放在入口。
4. **计费单位用「点」，不用 token**。token 不可感知 → 恐惧 → 不付费；1 点 ≈ 一次完整分析。
5. **¥4.9 是价格阈值**（大学生不用思考就能付，涨到 9.9 会掉一半转化）。「永久会员」实质是一次性买两件成本≈0 的权益 + 赠 20 点，毛利 92%。
6. **按百分比抽成在数学上不成立**（3% ≈ 0.055 分/次，月入 1 万需 90 万用户）→ 改成「成本 × 3 倍」，用户感知一样、收入差 90 倍。
7. **漏斗口径统一按人数**；**未消耗点数是负债，不是利润**。
8. **手机端是另一套信息架构**，不是缩小版桌面；手机改 → 电脑打是真实工作流。
9. **打印契约**：`@media print` 单独覆盖，输出 1 页 A4、保留文字层、PDF 体积稳定 172–175 KB。
10. **档案即记忆**：结构化 JSON + 每轮工具更新，不靠长上下文硬记。
11. **空档案回落样例**（按完整度判断）；**匿名 owner 按 IP+UA 隔离**（防共用一份简历）。
12. **日期型数字不能算量化证据**（「11 月我负责…」曾被误判为有数字）。
