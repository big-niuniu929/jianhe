## 三、环境与依赖（实测 2026-11-09）

### 已具备

| 依赖 | 版本/状态 | 用途 |
|---|---|---|
| Python | 3.14.8（`python` / `py -3` 均可用，pip 26.2.1） | 后端、脚本、Office 处理 |
| Node.js | v24.19.0 | 前端构建/截图脚本（如需要） |
| Git | 2.55.0.windows.4 | 版本控制、克隆参考库 |
| 浏览器 | Microsoft Edge（本机无 Chrome） | 截图/端到端验证（上一版已确认路径） |
| Tabbit CLI | 本会话提供浏览器自动化能力 | 需要时做真实页面验证 |
| GitHub 访问 | ✅ 已验证：`git -c http.sslBackend=openssl clone` 成功 | 参考库拉取 |
| 磁盘 | C: 可用 18.1 GB | 克隆参考库与构建 |

### 需注意的坑

| 问题 | 现象 | 处理 |
|---|---|---|
| Windows schannel | `git` / `curl` 直接访问 GitHub 报 `SEC_E_NO_CREDENTIALS` | 统一加 `-c http.sslBackend=openssl`（已封装进 `tools/fetch-refs.ps1`） |
| PowerShell 版本 | 本机是 Windows PowerShell **5.1**，没有 pwsh 7 | 所有脚本按 5.1 兼容编写；命令用 `powershell -NoProfile -ExecutionPolicy Bypass -File ...` |
| PowerShell 执行策略 | `npm.ps1` 被拦（npm 不可直接用） | 如需要 Node 包，用 `corepack`/`node` 直调；优先避免构建链 |
| pnpm 未安装 | `pnpm` 命令不存在 | 本产品优先零构建，暂不需要 |
| GitHub API 限流 | `api.github.com` 走共享出口 IP，403 rate limit | 用 `git clone` 而非 API；需要元数据时用网页/`raw` |
| 上一版无 docs/ | `简核/` 下文档已移到 `简核-发布前移出/docs/` | 盘点时已纳入 |

## 四、协作分工（Agent Teams）

概念确认后，我计划这样拆（同一个工作区、同一份文件系统）：

| 角色 | 负责 | 不碰 |
|---|---|---|
| **Lead（我）** | 概念定稿、架构决策、任务拆分、最终验收与汇报 | — |
| **研究员** | GitHub 参考库调研：每个候选项目的能力/许可/活跃度，产出 `refs/notes/*.md` | 产品代码 |
| **设计/前端** | 信息架构、交互原型、视觉与移动端 | 后端引擎 |
| **工程师** | 引擎复用与改造、接口、数据模型 | 视觉与文案 |

> 只有 3 人以上并行收益明显时才会开；小任务我自己做，避免协调开销。
> 每个共享任务先写清「写哪些文件」，避免两个人改同一文件。

## 五、汇报规则

每完成一步，我按固定格式汇报：

1. **做了什么**（一句话）；
2. **证据**（文件路径 / 命令输出 / 截图）；
3. **下一步**；
4. **需要你决定什么**（如果有）。

同时写进 `docs/03-进度台账.md`，你随时可以回看全过程。

## 六、风险清单

| 风险 | 影响 | 应对 |
|---|---|---|
| 概念文档缺失 | 无法开始设计，返工风险高 | 本清单 I-1 阻塞；不猜 |

| 参考项目许可问题 | GPL/AGPL 不能直接复制进产品 | `refs/README.md` 已写许可红线；每库笔记必须记 license |
| 网络/TLS 问题 | 拉不到参考库 | 已封装 openssl 方案；必要时你手动下载 zip |
