## 1. 主流程

```
工作台 ──▶ 简历（贴 JD → 看缺口 → 采用改写 → 导出）
   │              │
   │              ▼
   └────▶ 面试陪练（出题 → 作答 → 追问 → 评分）──▶ 复盘报告 ──▶ 错题本 ──▶ 再练
                                                    │
                                                    └──▶ 投递台账（记录进展）
```

## 3. 交互约定（已实现）

- **所有按钮都有反馈**：加载中禁用、成功后 toast、失败提示原因；
- **数据真实落库**：改写采用会写回档案并重算诊断；练习与报告写进 SQLite；
- **不编数据**：改写只做表达层，出现原文没有的数字会标注「待确认」（上版 fact_guard 逻辑）；
- **评分可解释**：每条分数指到「具体 / 可核查 / 角色边界 / 结果」四个检查点，并给一句改法；
- **移动端**：≤820px 顶部导航变底部 7 项 tab，三栏变单栏（预览优先）。
